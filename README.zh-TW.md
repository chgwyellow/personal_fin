# FinTrack

[English](README.md) · [繁體中文](README.zh-TW.md)

FinTrack 是一套以隱私為優先的 macOS 個人財務管理 App，將個人的財務狀況集中在同一個地方。它可以協助你了解目前擁有什麼、負擔什麼、投資表現如何，以及淨值長期的變化。

FinTrack 適合希望清楚掌握個人財務、但不想將財務資料交給線上帳號或訂閱服務的使用者。你可以管理現金、投資、負債、股利、定期投資與外幣餘額，同時讓原始資料保留在自己的 Mac 上。

App 的使用方式很簡單：先設定財務資料，再由 FinTrack 計算總額與投資價值，最後透過快照與歷史資料觀察整體財務狀況如何變化。需要時，程式會使用股價與匯率資料，但你手動輸入的資料仍然保留在本機。

## 功能

- 管理資產、負債、投資與淨值
- 建立手動與定時淨值快照
- 以不同時間區間查看淨值歷史
- 支援台股、美股與 ETF
- 管理外幣餘額、匯率與交易資料
- 查看投資組合市值、配置、資本損益與每日損益
- 管理定期定額計畫與手動輸入的投資交易
- 管理股利與損益表資料
- 所有資料以 SQLite 儲存在本機

## FinTrack 不提供的功能

FinTrack 是用於個人追蹤與分析的工具，不會代理下單、不會連接券商帳戶，也不會自動匯入交易資料。已完成的投資交易與定期投資內容，都必須由使用者手動輸入。

## FinTrack 的特色

- **完整的財務總覽：** 將資產、負債、投資與淨值集中查看，不必分開管理多份清單。
- **適合投資管理：** 追蹤股票與 ETF、實際交易、股利、定期定額、市值與每日損益。
- **有意義的歷史資料：** 建立快照並觀察財務狀況隨時間的變化，也能比較明細的月增減。
- **以本機為核心：** 不需要帳號或登入，財務資料庫只保留在自己的 Mac 上。

## 下載測試版

### 下載步驟

1. 開啟 [GitHub Releases](https://github.com/chgwyellow/personal_fin/releases)。
2. 點開最新版本，例如 `v0.1.1`。
3. 往下捲動到 **Assets**，必要時點擊展開。
4. 下載 **`FinTrack-0.1.1.zip`**。
5. 在「下載項目」中開啟剛下載的 ZIP。
6. 將解壓縮後的 `FinTrack.app` 移到 `/Applications`。
7. 第一次開啟時，對 App 按右鍵並選擇「打開」。
8. 如果 macOS 仍阻擋，請到「系統設定 → 隱私權與安全性」選擇「仍要打開」。

目前測試版只支援 Apple Silicon Mac，且尚未完成簽章與公證。未來版本的檔案名稱可能會有不同的版本號。

## 資料儲存與備份

第一次開啟 FinTrack 時，程式會自動建立資料夾、SQLite 資料庫與資料表，不需要手動設定。

資料庫位置：

```text
~/Library/Application Support/FinTrack/personal_finance.db
```

每個 macOS 使用者帳號都有自己的資料庫。安裝、移動或更新 App 不會刪除資料庫。測試新版本前，建議先備份：

```bash
cp "$HOME/Library/Application Support/FinTrack/personal_finance.db" \
   "$HOME/Library/Application Support/FinTrack/personal_finance.backup.db"
```

## 使用方式

1. 在「總覽」新增資產與負債。
2. 在「投資組合」新增股票或 ETF，並管理實際投資交易。
3. 在「定期定額」管理定期投資計畫。
4. 在「外幣」管理外幣餘額與交易資料。
5. 在「總覽」建立快照，追蹤淨值歷史。
6. 使用 App 內的「說明」查看各頁面的操作提示。

開啟相關頁面時，程式會更新股價與匯率。只要 Mac 能夠執行程式，定時快照就能依設定執行。

## 隱私與資料安全

FinTrack 不需要帳號或登入。財務資料只儲存在使用者自己的 Mac 上，不會由 FinTrack 上傳到外部服務。

## 已知限制

- 僅支援 macOS；目前發布檔僅支援 Apple Silicon
- 測試版尚未完成 Apple Developer ID 簽章、公證與自動更新
- 股價資料取決於外部公開 API 與支援的股票代號
- 定期定額功能不會自動下單，也不會自動匯入券商資料
